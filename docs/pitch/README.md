# EduNudg pitch deck

Sales pitch for education brand / institute owners (non-technical).

| File | Purpose |
|------|---------|
| `EduNudg-Pitch-Deck.pptx` | Ready-to-present deck (speaker notes on every slide) |
| `generate-edunudg-pitch-deck.mjs` | Regenerates the `.pptx` |

## Present

1. Open `EduNudg-Pitch-Deck.pptx` in PowerPoint / Keynote / Google Slides.
2. Turn on **Notes** / Presenter View — each slide has the spoken script.
3. Ideal runtime: **8–10 minutes** + optional live demo after slide 10.

## Regenerate

```bash
cd docs/pitch
npm install
node generate-edunudg-pitch-deck.mjs
```

## Honest scope

Do not pitch as live: full parent portal, dedicated attendance module, or full AI copilot.
